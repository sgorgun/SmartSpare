# ADR 0010: English-only repository

- Status: Accepted
- Date: 2026-11-16

## Context

The repository is shared with reviewers and may become public or be reused after the defence.

## Decision

All repository content — code, comments, documentation, diagrams, ADRs and commit messages — is written in English. No Russian text is committed.

## Consequences

- Consistent, internationally readable repository.
- Russian-language diploma materials live outside the repository.
