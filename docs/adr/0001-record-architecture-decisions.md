# ADR 0001: Record architecture decisions

- Status: Accepted
- Date: 2026-11-16

## Context

Architecture decisions for SmartSpare must be traceable for the diploma defence and for future work after the defence.

## Decision

Record every significant decision as a short ADR in `docs/adr/`, numbered sequentially, using the Context / Decision / Consequences format. An ADR is never edited after acceptance; a changed decision gets a new ADR that supersedes the old one. The consolidated view lives in [ARCHITECTURE_DECISIONS.md](../architecture/ARCHITECTURE_DECISIONS.md).

## Consequences

- Reviewers can see why each choice was made and which alternatives were rejected.
- Small overhead per decision.
