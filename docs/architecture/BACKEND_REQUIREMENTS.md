# SmartSpare — Backend Requirements Compliance

Status as of **27 November 2026**: release **v0.6.0**, the end of stage 6, Fleet ([CHANGELOG](../../CHANGELOG.md)). Stage 4 added the gateway and six service hosts, the RabbitMQ transport, public OpenAPI documents and Scalar, the Grafana stack locally and Grafana Cloud as code with a tested e-mail alert, container images, deploy workflows and Bicep. Stage 5 added the Inventory module and stage 6 the Fleet module, with the service-kit flow between them as integration events, retention of delivered messages and a scheduler in the single host. Nothing is deployed to Azure before stage 10 (#85). This matrix maps the backend grading rubric of the EHU diploma to evidence in the repository. The database part of the rubric is covered by [DATABASE_DESIGN.md §0](../database/DATABASE_DESIGN.md#0-requirements-compliance-matrix).

**Status values**

| Status | Meaning |
|---|---|
| **done** | Exists on `main` and can be shown. Evidence is a file, test, CI step or ADR. |
| **planned (stage N)** | Decided in the architecture or a stage plan. Not on `main` yet. |
| **gap** | Not covered by the plan yet. A `rubric` issue tracks it. |

A row is marked done only for what is on `main`, not for intentions. Each row is updated by the PR that changes its status.
